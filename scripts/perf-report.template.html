How far to trust these numbers

  • Frame rate and frame times are real, but for this computer. Emulation slows the CPU and cannot slow the GPU, so a real phone will be slower when the GPU is the limit. Use the Add a real phone box for true figures.
  • GPU memory is an estimate that adds up everything the invite uploads. Drivers add overhead on top.
  • JS memory is exact in Chrome. iPhones do not report it, so it is blank in pasted iPhone reports.
  • Page RAM and GPU process RAM are real measurements of Chrome's processes on this computer. They show trends and leaks well, but a phone's absolute figures will differ.
  • Triangles and draw calls are exact on every device. Peaks happen on frames that also redraw shadows.
  • A leak shows up as JS memory or RAM climbing steadily without levelling off.
